====================================================================
  WELLNESS - Calistenia Tracker
  Documentacion del proyecto
  ====================================================================

  QUE HACE LA APP
  ===============
  App de escritorio (Electron) para registrar entrenamientos de
  calistenia. El usuario se registra, elige un nivel (Principiante/
  Intermedio/Experto), y la app le muestra ejercicios adecuados a ese
  nivel. Puede registrar sesiones (series, repeticiones, notas), ver
  su historial, y un modulo IA analiza el progreso y recomienda cuando
  subir de nivel.

  No necesita internet. Todo se guarda local en SQLite.

  ====================================================================
  COMO FUNCIONA CADA PARTE
  ====================================================================

  1. index.html
  -------------
   - SPA con TODA la interfaz en HTML puro.
   - Sin estilos inline (todos movidos a clases CSS).
   - Secciones: login/registro (#pantalla-auth), luego el contenido
     principal (#contenido-principal) con 5 secciones: inicio, entrenar,
     progreso, catalogo, perfil.
   - Cada seccion es un <div class="seccion">. Solo una tiene clase
     "activa" a la vez.
   - Los JS se cargan al final en orden de dependencias.

   2. main.js
   ----------
   - Crea ventana Electron (1000x650, min 850x500).
   - nodeIntegration: true, contextIsolation: false.
   - Oculta barra de menu (autoHideMenuBar).
   - Abre en fullscreen.
   - Carga OPENROUTER_API_KEY desde .env si existe.
   - Atajos de teclado: F11 alterna pantalla completa, Esc sale
     de pantalla completa.
   - IPC handlers:
     * app-close: cierra la app (boton Salir del sidebar)
     * log-write: escribe una linea en wellness.log
     * ia-set-key: guarda API key en memoria
     * ia-analyze: envia prompt con sesiones + catalogo a OpenRouter,
       devuelve JSON con observaciones, recomendaciones, tecnicas,
       planSugerido, ejerciciosRecomendados[]

   LOG GENERAL (wellness.log)
   --------------------------
   - Archivo de log en la raiz (junto a wellness.db).
   - Formato por linea: [AAAA-MM-DD HH:MM:SS] [NIVEL] mensaje
   - Escribe el proceso principal via fs.appendFileSync.
   - El renderer llama ipcRenderer.invoke("log-write", {mensaje}).
   - Eventos registrados:
     * Inicio/cierre de la app
     * Registro, login, logout, eliminacion de usuario
     * Edicion de perfil
     * Sesiones guardadas, editadas y eliminadas
     * Cambio de tema (claro/oscuro)
     * Plan semanal actualizado
     * Analisis IA (inicio, exito, errores, sin key)
     * Ascenso de nivel

  3. clases.js
  ------------
  - Define las clases Usuario, Ejercicio, Rutina, Sesion.
  - NO se usan directamente (requisito de POO).

  4. database.js
  --------------
  - Abre/crea wellness.db con SQL.js.
  - Tablas:
    * usuarios (id, nombre, nivel, peso, altura, objetivo, creado_en)
    * progresiones (id, grupo_muscular, nombre, nivel, reps, series, desc)
    * sesiones (id, usuario_id, progresion_id, series_hechas, reps_hechas,
                notas, fecha)
    * plan_semanal (usuario_id, dia, grupo_muscular)
  - Funciones globales (window.xxx):
    * iniciarDB(), crearUsuario(), obtenerUsuarioPorId()
    * actualizarUsuario(), eliminarUsuario()
    * guardarSesion(), obtenerSesiones(id,lim)
    * actualizarSesion(), eliminarSesion()
    * inicializarPlanSemanal(), obtenerPlanSemanal(), guardarPlanSemanal()
    * obtenerProgresionesPorGrupo(grupo, nivelMaximo) — filtra por
       grupo y nivel
    * obtenerTodasProgresiones(nivelMaximo) — todos los ejercicios
       hasta un nivel (usado por IA para recomendar alternativas)
  - guardarDB() se llama tras cada escritura.

5. app.js
   ---------
   - Declara var usuarioActual = null (global).
   - Define logEvento(accion, detalle): helper global que envia
     eventos al proceso principal para escribirlos en wellness.log.
   - Al cargar, llama a iniciarDB(), poblarProgresiones(), y muestra
     login.

  6. auth.js
  ----------
  - Login: lista de usuarios guardados.
  - Registro: formulario con nombre, nivel, peso, altura, objetivo.
  - iniciarSesion(id): carga usuario, muestra sidebar y contenido.
  - cerrarSesion(): vuelve al login.
  - actualizarInfoUsuario(): llena sidebar y perfil.

  7. progresiones.js
  ------------------
  - CATALOGO: array de 100+ ejercicios. Cada uno:
    grupo, nombre, nivel (1-3), reps, series, desc.
  - poblarProgresiones():
    * Normaliza niveles (max 3, min 1)
    * Si DB vacia: INSERT todo el CATALOGO
    * Si DB tiene datos: INSERT los que faltan, UPDATE los que
      cambiaron (nivel/reps/series/desc)
  - mostrarCatalogo(): renderiza tabla en seccion Catalogo.
  - poblarSelectEjercicios(): llena <select> en Entrenar, filtrando
    por nivel del usuario.

  8. ejercicios.js
  ----------------
  - mostrarMetaEjercicio(): al seleccionar ejercicio, muestra su meta
    (series x reps) y descripcion.
  - guardarSesionClick(): toma datos del formulario, guarda via
    guardarSesion(), muestra si cumplio la meta.

  9. navegacion.js
  ----------------
  - cambiarSeccion(id, boton): muestra/oculta secciones. Al abrir
    "inicio" llama a refrescarHistorial(), mostrarResumenDiario().
    Al abrir "progreso" llama a refrescarHistorial().
    Al abrir "catalogo" llama a mostrarCatalogo().

  10. plan-semanal.js
  -------------------
  - refrescarPlanSemanal(): muestra plan de la semana con el dia
    actual destacado. Para cada dia, lista los ejercicios
    recomendados del grupo muscular correspondiente, filtrados por
    nivel del usuario.
  - mostrarResumenDiario(): tarjeta con X/Y ejercicios completados hoy.
  - mostrarEditorPlan(): formulario para editar el plan semanal.

  11. historial.js
  ----------------
  - refrescarHistorial(): muestra ultimas sesiones en Inicio y en
    Progreso, con botones Editar/Eliminar.
  - editarSesionClick(): modal para modificar series/reps/notas.
  - eliminarSesionClick(): confirmacion y borrado.

   12. ia.js (472 lineas)
   ---------
    - Analisis dual: IA via OpenRouter (si hay API key) + local (siempre).
    - Coach IA via OpenRouter (modelo gratis por defecto: openrouter/free,
      un router que elige un modelo gratis disponible. Configurable con
      OPENROUTER_MODEL en .env para fijar uno especifico):
      * Usa la API compatible con OpenAI via fetch (sin SDK)
      * Recibe sesiones recientes, plan semanal y CATALOGO completo
      * Sugiere ejercicios alternativos del catalogo segun debilidades
      * extraerJSON() en main.js: parsea la respuesta aunque venga
        envuelta en ```json``` o con texto extra
    - Local (rule-based, siempre visible):
      * analizarNivel(): evalua si puede subir (60+ dias, 15+ sesiones,
        60%+ metas cumplidas). Barra de progreso visual.
      * analizarTendencia(): compara volumen semanal vs semana pasada
      * analizarEstancamiento(): detecta ejercicios sin mejora en 3
        sesiones consecutivas y sugiere alternativas del catalogo
    - Funciones helper:
      * crear(tag, clase, texto): reemplaza createElement+className+textContent
      * nivelMaximo(): mapea nivel string a numero
      * usarDiasTranscurridos(): calcula dias desde registro
      * crearBarraProgreso(): renderiza barra de ascenso
    - confirmarSubirNivel(): cambia nivel y felicita.
    - cancelarSubirNivel(): descarta (usa resultadoIA directo, no volcar).

  13. idiomas.js
  --------------
  - dict: objeto con traducciones ES y EN.
  - t(clave): busca en el idioma actual.
  - getIdiomaActual(): lee <select id="select-lang">.
  - aplicarTraduccion(): al cambiar idioma, traduce textos estaticos
    y re-renderiza la seccion activa.

  ====================================================================
  FLUJO DE DATOS
  ====================================================================

  Registro:
    formulario → crearUsuario() → INSERT INTO usuarios → wellness.db

  Login:
    clic en usuario → obtenerUsuarioPorId() → SELECT FROM usuarios
    → objeto usuarioActual (global)

  Catalogo:
    poblarProgresiones() → INSERT/UPDATE INTO progresiones
    mostrarCatalogo() → SELECT FROM progresiones → HTML

  Entrenar:
    poblarSelectEjercicios() → SELECT WHERE nivel <= nivelMaximo
    → <select>
    guardarSesionClick() → guardarSesion() → INSERT INTO sesiones

  Plan semanal:
    inicializarPlanSemanal() → INSERT INTO plan_semanal (default)
    obtenerPlanSemanal() → SELECT FROM plan_semanal
    guardarPlanSemanal() → UPDATE plan_semanal

IA:
     obtenerSesiones() → iaAnalizar() (via OpenRouter) + analisis local
     → coach card (IA) + nivel/progreso/tendencia/estancamiento (local)
     → HTML
     La IA recibe el catalogo de ejercicios y puede recomendar alternativas
     especificas segun debilidades detectadas.

  ====================================================================
  MODIFICAR O AGREGAR FUNCIONALIDAD
  ====================================================================

  - Para agregar ejercicios: editar CATALOGO en progresiones.js.
    No hace falta borrar DB; poblarProgresiones() agrega los que
    faltan y actualiza los existentes.
  - Para cambiar colores: editar styles/base.css (variables CSS).
  - Para agregar traducciones: agregar claves en dict (idiomas.js).
  - Para cambiar plan por defecto: editar inicializarPlanSemanal()
    en database.js.
   - Para cambiar requisitos de ascenso: editar valores en ia.js
     (diffDias >= 60, sesiones >= 15, porcentaje >= 60).
   - Para cambiar modelo de IA: editar MODELO_IA en main.js o setear
     OPENROUTER_MODEL en .env (ej: google/gemma-2-9b-it:free).
   - Para cambiar colores del tema: editar variables CSS en
     styles/variables.css (modo claro y body.dark-mode).
   - Para estilos: usar clases en vez de inline styles.
      Utilitarios: .mt-8, .mt-12, .mt-15, .mb-10, .icon-vmiddle,
      .logo-img, .texto-placeholder, .texto-sin-objetivo, .card-meta.
      IA: .ia-texto-success, .ia-texto-warn, .ia-texto-error,
      .ia-texto-danger, .ia-texto-muted, .ia-texto-exito, .ia-texto-preg,
      .ia-texto-sugerencia, .ia-texto-muted-vol, .ia-card-warn,
      .ia-card-error, .ia-flex-row, .ia-input-key, .ia-btn-guardar-key.
    - El modal de registro se genera dinamicamente desde auth.js;
      el HTML estatico de #modo-registro esta vacio a proposito.
    - ia.js no tiene estilos inline (solo 4 asignaciones dinamicas:
      display, width de barra, marginTop, color de icono).
